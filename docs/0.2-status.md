# 0.2 requirement map

The detailed original specification is [0.2-requirements.txt](0.2-requirements.txt). The release is a Windows x64 beta; environment/measurement limits are recorded rather than hidden.

| Area | Implementation and evidence |
|---|---|
| Audit/baseline | Prior beta preserved; baseline in benchmarks/0.2-baseline.txt; changes in separate development commits. |
| Native glass UI | DWM Mica/Acrylic, rounded surfaces, native v6 controls, Segoe UI, theme/transparency/animation and text-size preferences. Embedded manifest enables visual styles, per-monitor v2 DPI and long paths. |
| Explorer navigation | Back/forward/up/address, known favorites, drives, recent files, saved pins; virtual details/list/icon views, native multiple selection, loaded-page sorting and context actions. |
| Spotlight | Separate centered window, shared SearchIndex, cancellation/generation checks, paths/types/icons, location button and keyboard actions; opt-in configurable global hotkey with conflict handling. |
| Memory modes | Estimate before complete table load; total/available system RAM and file/folder counts; mode descriptions and all three profiles and target budget saved; repeated startup uses checked caches. |
| Filters/ranking | Categories, extensions, path scope; optional exact/prefix/word/substring/frequency ranking of bounded pages without changing engine cursors. |
| Metadata | Independent on-selection worker, dates/attributes/logical size and explicit unavailable/physical-size states. |
| USN | Persistent FRN lookup and stable IDs; incremental posting changes, live create/rename/move/parent-rename/delete test, stale/error states, persistent indexing exclusions and no repeated full rebuild for small notifications. Directory moves across exclusions explicitly require rebuild; directory anchors remain structural. |
| WinDirStat | Registry/known/portable/manual discovery; remembered downloads and executable paths; cancellable official SHA-256 and Authenticode checked download/cache; explicit installer confirmation and normal Windows UAC; official-page fallback. |
| Storage | Streaming metadata-only JSON/CSV/Markdown, directory/volume/category/top summaries, safe/neutral names, exclusions, depth/size/compact controls, progress/cancellation and split reports. |
| AI report | Local compact Markdown, methodology/partial-data cautions and copyable review prompt. No AI API or automatic transmission. |
| Settings | Separate seven-section window, current process RAM/object/cache/index/search information and About. Third-party notices are included; application license has not been selected by the owner. |
| Performance | Separate CLI engine, GUI and analyzer measurements; bounded icon/history caches and no decorative idle loop. |
| Tests | 32 automated cases plus actual hidden GUI, live elevated USN, full metadata export and verified WinDirStat download/cache/cancel/tamper/portable-launch checks. Windows/MSVC CI independently checks the source. |
| Delivery | Versioned GUI/CLI package, notices, instructions, hashes and source revision; GitHub release publication is explicitly authorized by the user. |

Visual pixel fidelity, physical mixed-DPI/multi-monitor presentation, screen-reader behavior and GPU traces are not claimed as validated: available hardware is one 96-DPI monitor and screen capture remains disabled. Geometry is tested at 96/120/144/192 DPI with negative-coordinate monitors. Column sorting/ranking cover loaded pages, not a global ordering of all matches. Physical disk allocation and confirmed duplicates are not inferred from logical metadata. Windows Installer itself is external; automated checks do not complete an installation on the user's machine.

Methods and limits: [UI_PERFORMANCE.md](../UI_PERFORMANCE.md), [STORAGE_ANALYSIS.md](../STORAGE_ANALYSIS.md), [BETA_TEST_REPORT.md](../BETA_TEST_REPORT.md), [VALIDATION.md](../VALIDATION.md).
