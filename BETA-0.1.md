# HyperSearch beta 0.1

Нативный поиск имён файлов Windows 10/11 x64 с упрощённым интерфейсом Проводника.

## Запуск

Распакуйте ZIP в отдельную папку и запустите `HyperSearch.exe`. Установка не требуется. В исходной локальной сборке GUI называется `hypersearch-gui.exe`, консоль — `hypersearch.exe`; в ZIP консоль переименована в `hypersearch-cli.exe`.

При первом запуске дождитесь оценки RAM, выберите режим и нажмите «Применить и загрузить». Для тестирования выбран fast; экономный и собственный бюджет доступны в параметрах. Для полной быстрой NTFS-индексации запустите GUI от администратора. Без такого доступа используется обход доступных каталогов, возможна неполнота из-за прав доступа. Существующий снимок доступен обычному пользователю с пометкой непроверенной актуальности.

## Интерфейс

* «Этот компьютер» в боковой панели — поиск по всему загруженному индексу. Нажмите диск для просмотра его содержимого.
* Адресная строка и Enter/кнопка → — переход в папку, которая присутствует в индексе. ← возвращает назад, ↑ поднимает на уровень выше.
* В открытой папке без запроса показаны непосредственные дети. С запросом поиск идёт по именам внутри этой папки и потомков.
* Таблица: имя, полный путь, тип. Двойной щелчок по папке открывает её внутри HyperSearch, по файлу — системное приложение по умолчанию.
* «Расположение» переходит в родительскую папку выбранного файла внутри HyperSearch.
* «Обновить» перечитывает сохранённый индекс и доступный USN. «Параметры» раскрывает выбор RAM, источника индексации и кнопки «Индексировать» / «Все диски».
* Страница содержит до 100 результатов, «Ещё 100» добавляет следующую. Полного подсчёта всех совпадений нет.

Готовые таблицы сохраняются в кэш и используются при повторном запуске. Поиск не выполняет копирование, переименование, перенос или удаление пользовательских файлов. Открытие выбранного файла запускает его системную ассоциацию, включая запуск исполняемых файлов.

## Известные ограничения beta

GUI работает со снимком на момент загрузки/обновления; непрерывное обновление во время сессии пока отсутствует. Нет сортировки колонок, системных иконок файлов, предпросмотра, изменения размеров/дат и файловых операций. Навигация показывает только объекты индекса. Внутрь junction/reparse points обход не выполняется. USN-перечисление сохраняет одно имя на FRN; для всех доступных hard-link путей используйте обход `--walk`.

Бинарники beta не подписаны цифровым сертификатом. Windows может показать предупреждение о неизвестном издателе; программа не меняет настройки защиты.

## Статистика и проверка

Подробности: `BETA_TEST_REPORT.md`, `CACHE.md`, `MEMORY_MODES.md`, `VALIDATION.md`, `PERFORMANCE.md`. Публикуемые логи содержат агрегированные замеры и стандартные тестовые пути; локальный файловый индекс и настройки в релиз не входят.

Визуальная проверка через захват экрана не проводилась по просьбе владельца тестовой машины. Нативный ListView проверен программным тестом в невидимом окне: колонки, Unicode-текст, выбор строки и навигационные запросы. Полное тестирование интерфейса на разных DPI и нескольких мониторах ещё требуется.
