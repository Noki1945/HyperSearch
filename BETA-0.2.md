# HyperSearch 0.2 beta — Windows x64

Распакуйте ZIP и запустите HyperSearch.exe. Установка, автозагрузка и глобальные клавиши по умолчанию не включаются. Отдельный EXE — тот же GUI; hypersearch-cli.exe находится в ZIP.

При первом запуске программа оценивает объём индекса и RAM. Выберите экономный, сбалансированный, быстрый режим или собственный бюджет и примените выбор. По умолчанию для тестирования предлагается быстрый режим. При повторном запуске используются сохранённые настройки и проверенные таблицы на диске. Для первичного полного NTFS-индекса и USN нужны права администратора; обычный запуск может искать по сохранённому снимку с предупреждением об актуальности. Кнопка «Все диски» обрабатывает доступные корни букв дисков.

В строке поиска введите имя или его часть. Адресная строка задаёт область; «Этот компьютер» — весь загруженный индекс. Есть категории, расширения через запятую и необязательная релевантность. Дополнительный синтаксис: `ext:exe,dll type:apps in:"C:\Work Files" rank:on`. Двойной щелчок открывает папку внутри HyperSearch либо файл в связанном приложении. «Расположение» переходит к родительской папке. Контекстное меню и Ctrl+C копируют пути; Ctrl+F/Ctrl+L переводят фокус; Alt+стрелки работают с историей. «Ещё 100» догружает страницу. Сортировка и релевантность применяются к загруженным страницам.

«Быстрый поиск» открывает Spotlight. Стрелка вниз переводит фокус к результатам, Enter открывает, Escape скрывает окно. В параметрах можно явно включить собственную глобальную комбинацию, например Ctrl+Alt+Space; `off` отключает её. Занятые сочетания показываются как ошибка.

Параметры открываются отдельно и содержат семь разделов. Системные стеклянные поверхности и скругления зависят от Windows; прозрачность и анимация отключаются. Интерфейс использует нативные элементы управления и не является точной копией macOS.

Режим и оценка RAM находятся в разделе «Поиск», размер текста — во «Внешнем виде». Кнопка «Информация» скрывает боковую панель метаданных. В «Индексации» видны статус USN и последнее обновление; исключения задаются абсолютными путями через `;`. Кнопка сохранения перестраивает индекс. Имена каталогов-связей сохраняются для USN, но скрываются из поиска и отчётов. Перенос папки через границу исключения требует перестроения; удаление исключения тоже требует перестроить индекс для возврата пропущенных файлов.

В «Хранилище» можно открыть уже установленный/скачанный WinDirStat. Путь запоминается и проверяется повторно. Если программы нет, кнопка скачивает официальный x64-пакет, сверяет SHA-256 и отдельно предлагает запустить установщик через обычный интерфейс Windows/UAC. «Нет» сохраняет пакет без установки; повторное открытие использует проверенный кэш. Активная загрузка отменяется той же кнопкой. При ошибке доступен официальный сайт. Проверяемые загрузки используют входящий в Windows PowerShell; поиск и отчёты не запускают этот помощник.

Для локального отчёта HyperSearch выберите область, формат, приватность, глубину, минимальный размер и исключения. Предпросмотр показывается перед сохранением. Экспорт работает отдельно от поиска, поддерживает отмену и разбиение на части. «Отчёт для ИИ» создаёт компактный Markdown; никакой отправки в сеть нет. Имена файлов могут оставаться личной информацией даже после скрытия имени пользователя.

Это beta: физические тесты нескольких мониторов с разным DPI и визуальная проверка всех тем не выполнены, поскольку захват экрана отключён по просьбе пользователя. Физическое место на диске и дубликаты не вычисляются; отчёт содержит логические размеры и ограничения подсчёта. USN не гарантирует все hard-link имена. Отключённые диски, ресурсы без буквы и закрытые каталоги могут отсутствовать. Движок ищет по именам, а не по содержимому документов.
